TASK PRIORITY MANAGEMENT SYSTEM

Files:
- app.py: Complete Flask website, embedded HTML/CSS/JavaScript, API routes, DSA algorithms, and SQLite database initialization.
- requirements.txt: Python package requirement (Flask).
- run.bat: Windows launcher that installs Flask and starts the website.
- tasks.db: Created automatically the first time app.py runs.

HOW TO RUN:
1. Extract the TaskPriorityWebsite folder to Downloads or another easy-to-find location.
2. Ensure Python is installed and the py command works in PowerShell.
3. Double-click run.bat, or open PowerShell in this folder and run:
   py -m pip install -r requirements.txt
   py app.py
4. Open http://127.0.0.1:5000 in your browser.
5. Keep the terminal open while using the website. Press Ctrl+C in the terminal to stop it.

The database is created automatically and initially contains 25 sample tasks.
